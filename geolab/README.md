# ГЕОлаб — интерактивный атлас мира

Открыть сайт: https://sultanamangholov2003-ops.github.io/geolab/

Статический учебный атлас с вращающимся глобусом, 8 территориями, исследованием, играми и геомиссиями. Включает Казахстан, карты областей, города, реки, озёра и другие географические объекты.

Все необходимые файлы находятся в этой папке. Сборка и серверная база данных не требуются. Для локального запуска используйте обычный HTTP-сервер; открытие через file:// не поддерживает загрузку JSON-карт. Результаты и наборы учителя сохраняются только в localStorage браузера.

Источники карт и лицензии указаны внутри сайта в разделе «О проекте и источники» и в assets/. Контуры обзорные; административные данные Казахстана относятся к 2024 году. Для пустынь и природных зон используются опорные точки.
